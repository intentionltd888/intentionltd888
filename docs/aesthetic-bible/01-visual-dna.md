# 01 · Visual DNA

> 狀態：**初步觀察**。依據只有一張 IG 網格截圖（17 支作品縮圖），沒有看過影片本身、旁白或 Pinterest。完整收集後要整章重寫，下面每一條都要用數據驗證或推翻。

## 從網格截圖看到的系列

### A. 黑底瓷盤靜物（數量最多，約 8 支）
- 純黑背景、俯拍、白色古典浮雕瓷盤（橢圓或圓）放在畫面正中央，盤上只放**一個**物件。
- 物件刻意錯置：鮭魚、螞蟻、Cybertruck 模型、銀色金屬唇、一疊美鈔、紅口紅、生牛排。
- 色彩極度克制：黑、白、加上物件本身唯一的顏色，例如口紅和牛肉的紅。
- 同一系列還有去背的乳牛頭，懸浮在黑底上，同一套語言但沒有盤子。

### B. 黑底單一主體／暗黑儀式感
- 白色長毛貓、機械骷髏士兵、銀色翅膀的天使雙人像、飛散紅色花瓣中張開雙臂的人：主體置中，黑底，有地面反射，像博物館陳列或精品廣告的打光。
- 白髮老婦坐在長桌一端，銀燭台對稱排列：哥德式的晚餐儀式。
- 黑長髮女性纏著鍊條，周圍飄著白色紙片或花瓣：J-horror 和哥德的人像。

### C. 東亞場景、生活質感
- 日本教室、黑板上畫著鳥居、桌上散落紙鶴、黑洋裝少女：自然光、偏暖、底片或手機的寫實質感。
- 光頭小孩戴金牙咧嘴笑：近距離、高飽和、像底片快照的街頭人像。
- 背上斜插武士刀的裸背線稿或插畫：少數插畫風格。

## 暫定的共通原則（待驗證）
1. **單一主體、置中、極簡背景**：黑底是預設值。
2. **錯置帶來意象**：日常物件放進儀式化的容器（瓷盤）裡，靠並置產生意義。比起好看，更在意「這是什麼意思」。
3. **兩種質感並行**：棚拍和精品式的乾淨黑底；手機、底片式的生活寫實感。
4. **畫幅 4:3**。
