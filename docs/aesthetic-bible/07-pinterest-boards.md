# 07 · Pinterest 圖板消化

來源：Pinterest `alohajie`，共 55 個圖板，約 2,229 個 pin，於 2026-10-18 爬取。每個圖板做成縮圖網格後逐格看過。以下依圖板記錄看到的東西，結論統整在 `01-visual-dna.md`。

> 權重：**個人美學圖板**（名稱前有 A｜、B｜，或沒有加【】的）代表 Aloha 自己的喜好，權重高。**【案名】圖板**是接案時的方向參考，代表他們能駕馭的範圍，權重低。

## 個人美學圖板

### 【 MY BOARD 】（22）
同時存在兩個極端：
- **韓系近距離美妝特寫**：腮紅泛紅、唇有水光、髮絲掠過臉，前景放一朵虛焦的花（百合、非洲菊）框住臉；粉嫩、柔光、皮膚有真實質地。
- **宇宙極簡**：黑底配橘色光的漸層和光暈，巨大的空間裡只有極小的人，太陽圓裡站著一個剪影，星空中只有一個白點。
- 另外有紅色房間裡的時裝照、植物配排版的 editorial、戴銀框眼鏡穿繞頸上衣的人像。

### A｜INTENTION.made UNSEEN Series（25）
拉絲不鏽鋼、浮雕字、金屬吊牌、鑰匙圈、五金、鍍鉻；灰階的街頭服裝（Balenciaga、洗舊的帽T、丹寧）；刻在金屬上的草寫體或哥德體 logo。整體是「銀色工業感的周邊商品」語言。

### unseen new（14）
美術館和清水模建築的極簡空間：窗框框住富士山、戴帽T看不到臉的人站在古典名畫前、白底上一隻手拿著磁碟片、鍍鉻手錶，高反差黑白。**匿名人物放進宏大的古典空間**。

### A｜LIKE（29）
Y2K 和 indie sleaze 的時尚 editorial：閃光燈直打、粉藍絲襪、地板上雕塑感的姿勢、挖洞的衣服、鍍鉻心臟、紅色大字的雜誌版式、貓和模特兒同框。

### A｜Just LIKE（14）
超現實的錯置：雲朵載在卡車上、戒指盒裡放 SD 卡、浴缸裡漂滿青蘋果、一本書攤開是嘴唇、骷髏剪紙配火焰，還有戲謔的產品廣告。**這組和 IG 的黑底瓷盤系列同源：把日常物件放進不屬於它的容器。**

### Neo-futurist editorial（44）
鍍鉻和液態金屬的產品、白底柔光、單件物體懸浮、Gentle Monster 風格的未來感眼鏡、機械手拿太陽眼鏡、灰白的冷調。

### robot（31）

### B｜GIRL（25）

### A｜INTENTION CIS（90）

### A｜STUDIOS（42）／A｜HOME（16）
