# Aloha 美學 Skill

完整依據在 `docs/aesthetic-bible/`。這份 skill 是操作入口，只放流程和 checklist；美學判斷以 bible 為準。

> 狀態：骨架。標記「待補」的段落要等 IG、Pinterest、本機素材收集完成後，由 Phase 2 消化結果填入。不要用想像補上去。

## 開工前
1. 先讀 `docs/aesthetic-bible/01-visual-dna.md`，確認這次的題材屬於哪個系列。
2. 從 `docs/aesthetic-bible/06-works-catalog.md` 找最接近的既有作品當錨點，並從 `data/derived/` 拿它的 contact sheet 和鏡頭表。
3. 能餵參考圖就餵參考圖。不要只靠文字 prompt 生出整個風格。

## 生圖 checklist（待補：03-image-generation.md）
- [ ] 畫幅 4:3
- [ ] 媒材感明確：手機、閃光直打、底片，選一種，不要「cinematic 8k」那種萬用 AI 感
- [ ] 有參考圖，並寫明要從參考圖拿構圖、光、色或質地中的哪一項
- [ ] 對照 `08-anti-patterns.md`
